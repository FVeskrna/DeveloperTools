## What it does

Generate 1–1,000 UUIDs at once — random v4 or time-ordered v7 — formatted the way your target system wants them: uppercase, braced, or hyphen-less. A separate inspector validates any UUID you paste and identifies its version, variant, and (for v7) the creation timestamp embedded in it.

## Examples

**Seeding test data.** Set count to 100, COPY ALL, and paste into your fixture file. Every id comes from the browser's cryptographic RNG, so there are no accidental duplicates from a weak seed.

**A GUID for a C# or SQL Server context.** Enable UPPERCASE and BRACES to get `{9B2F5C1E-8D3A-4C7B-A1E0-5F4B3C2D1E0F}` — the registry/COM-style format Microsoft tooling expects, without hand-editing.

**"What is this id in our database?"** Paste an unknown UUID into the inspector. If it reports `v7 — unix-time + random` with a timestamp of last Tuesday 03:14 UTC, you now know both that it was machine-generated recently and roughly which deploy created it.

## Edge cases & notes

- **v7 support is native here** — the timestamp is placed in the first 48 bits per RFC 9562, so ids generated in the same batch sort lexicographically by creation moment (ties broken by random bits).
- **Hyphen-less output** is 32 hex characters; the inspector accepts that form back, so round-tripping works.
- **The version digit is position 13** (first digit of the third group) and the variant is the first digit of the fourth group (8, 9, a, or b for standard UUIDs) — that's all the inspector needs, no server lookup involved.
- `crypto.randomUUID()` requires a secure context (HTTPS or localhost); on plain HTTP the generator can't run — this site is HTTPS, so it only matters if you self-host the page.
