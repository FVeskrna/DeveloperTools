## What it does

Type a pattern and test text; every match is highlighted instantly and broken out into a table with positions and capture groups. It uses the browser's native JavaScript RegExp engine, so what matches here matches in your code — no server round-trip, no flavor surprises.

## Examples

**Extract email addresses from a log dump.** Press the EMAIL quick-insert. Against a line like `jana.novak@example.com opened #4411`, the match table shows the full address, and with the pre-filled pattern `(?<user>\w[\w.]*)@(?<host>[\w.-]+\.[a-z]{2,})` you get `user` and `host` as named groups — ready to map to replacement syntax like `$<user>`.

**Validate IPv4 addresses strictly.** The IPV4 quick-insert uses range-checked octets — `(25[0-5]|2[0-4]\d|1\d\d|[1-9]?\d)` — so `192.168.0.14` matches but `999.1.1.1` does not. A naive `\d+\.\d+\.\d+\.\d+` would accept both.

**Find duplicated words.** Pattern `\b(\w+)\s+\1\b` with flags `gi` catches accidental repetitions like "the the" using a backreference. The GROUPS column shows what `$1` captured for each hit.

## Edge cases & notes

- **Zero-length matches** (e.g. pattern `a*` matching between characters) are listed as `(empty)` in the table; the engine advances one character so the loop always terminates.
- **The `m` flag** changes `^` and `$` to match at line boundaries; without it they anchor to the whole input.
- **The `s` flag** lets `.` cross newlines — useful for matching multi-line blocks.
- Matches are capped at 1,000 rows to keep the page responsive on huge inputs; the count label still reflects the true total up to that cap.
