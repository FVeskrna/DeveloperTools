## What it does

Four synchronized panes — binary, octal, decimal, hex — where editing any one instantly rewrites the other three. Below them, a byte-grouped bit map shows exactly which bits are set, sized to 8, 16, 32, or 64 bits as needed.

## Examples

**Reading a file permission.** Octal `755` → binary `111101101`: the classic `rwxr-xr-x` pattern is visible directly in the bit map.

**Decoding a flags enum.** A status field stores `2054`. Hex pane shows `806`, binary shows bits 1, 2, and 11 set — so flags `0x2`, `0x4`, and `0x800` are active. The popcount label confirms three flags.

**Checking a bitmask constant.** `0xFF00` in hex lights up exactly the high byte of a 16-bit view — an off-by-one in a shift is immediately visible as a misaligned block.

## Edge cases & notes

- **Precision is exact.** Values beyond 2^53 lose precision in ordinary JavaScript numbers, but BigInt conversion keeps every digit — paste a 64-bit ID from a database without fear.
- **Leading zeros** are accepted on input and normalized away on output (`0755` in the octal pane is fine).
- **The decimal pane rejects hex digits** rather than guessing — each pane validates against its own base and reports which base failed.
- Bit numbering in the visualization runs MSB → LSB, matching how you'd write the number on paper.
