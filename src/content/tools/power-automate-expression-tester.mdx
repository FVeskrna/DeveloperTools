## What it does

Type a Workflow Definition Language expression — the language behind Power Automate's expression editor — and see the evaluated result and its type immediately, without saving a flow and running it. A sample-data panel stands in for `triggerBody()`, `variables()`, `items()`, and `outputs()`, and a grouped function reference inserts any of the ~70 supported functions at your cursor.

## Examples

**Format today's date.** The pre-filled `formatDateTime(utcNow(), 'yyyy-MM-dd')` returns today as `2026-07-17` — and switching the format string to `dd/MM/yyyy` or `ddd d MMMM` shows the result instantly, which beats the save-run-check loop for finding the right format string.

**Null-safe field access.** `coalesce(triggerBody()?['account']?['fax'], 'not provided')` against the sample payload returns `not provided` — the `?[]` operator and `coalesce` pattern that prevents the classic "InvalidTemplate: cannot be evaluated because property doesn't exist" failure. Delete the `?` and the tester shows you exactly the error a real run would produce.

**Date arithmetic for an SLA.** `dateDifference(triggerBody()?['createdon'], utcNow())` (add a `createdon` timestamp to the sample data) returns a `d.hh:mm:ss` timespan; wrap it in `startsWith(...)` checks or compare `ticks()` values for threshold logic.

## Edge cases & notes

- **Integer division is faithful:** `div(10, 4)` returns `2`, exactly as a flow does — the number-one silent math bug. One caveat: JSON has no float literals, so `10.0` reads as the integer `10` here, whereas the Azure runtime float-divides for `div(10.0, 4)`.
- **String comparisons are case-insensitive** (`indexOf`, `startsWith`, `endsWith`), matching WDL — but `equals()` is case-sensitive, also matching WDL. Yes, that inconsistency is the platform's.
- **`if()` and `and()`/`or()` short-circuit** — the untaken branch never evaluates, so `if(equals(x, null), 'none', triggerBody()['x'])` is safe here as in a flow.
- **`convertTimeZone` accepts Windows time-zone names** (`'Central Europe Standard Time'`) via a curated map, plus any IANA id — handy since the official docs only list the Windows names.
- Unsupported functions (`xpath`, `workflow`, …) return *Function 'x' is not supported in this tester* — a graceful stop, never a wrong answer.
